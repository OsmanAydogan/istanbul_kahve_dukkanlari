# ☕ Kahve Dükkanı Konum Optimizasyonu

İstanbul'da kahve dükkanları için **optimal lokasyonları** belirleyen web uygulaması.

## Kurulum

```bash
pip install -r requirements.txt
```

## Çalıştırma

```bash
python app.py
```

Tarayıcıda aç: http://localhost:5000

## Kullanım

1. **Talep Noktaları**: Hizmet verilecek yerleri ara ve ekle
2. **Aday Konumlar**: Dükkan açılabilecek yerleri ara ve ekle
3. **Optimize Et**: Optimal konumları hesapla

## Gereksinimler

- Python 3.8+
- Google Maps API Key (`.env` dosyasında)
